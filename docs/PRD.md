# Chat 问日程功能 - PRD

## 1. 文档概览

### 1.1 功能名称
Chat 智能日程查询

### 1.2 目标用户
- 使用桌面宠物 AI 对话功能的用户
- 需要快速查询日程的用户
- 希望通过自然语言了解日程安排的用户

### 1.3 核心价值
在 AI 对话中集成日历查询能力，用户可以用自然语言询问日程，AI 基于真实日历数据智能回答。

---

## 2. 用户故事与范围

### 2.1 用户故事

**作为用户，我想要：**
1. 在聊天界面点击"问日程"按钮，快速查询今日日程
2. 用自然语言问"今天有什么会议？"，AI 能基于真实数据回答
3. 问"明天的日程是什么？"或"这周有什么安排？"，AI 能正确回答
4. 日历未配置时，AI 提示我先配置日历
5. 日历无数据时，AI 告知我今天没有日程

### 2.2 范围

#### In-Scope

1. **快捷模板按钮**
   - 在快捷模板栏添加"📅 问日程"按钮
   - 点击后自动填入默认问题并发送

2. **自然语言检测**
   - 检测用户输入中的日程相关关键词
   - 关键词包括：日程、会议、安排、行程、今天有什么、明天有什么、这周

3. **上下文注入**
   - 查询本地日历数据（今日 + 未来24小时）
   - 格式化日程信息
   - 注入到用户消息中作为 AI 上下文

4. **AI 智能回答**
   - AI 基于注入的日程数据回答用户问题
   - 支持今日、明日、本周等时间范围查询

#### Out-of-Scope
1. 日历事件创建/编辑
2. 日程冲突检测
3. 语音查询
4. 日程统计分析

## 3. 功能需求

### 3.1 快捷模板

#### 3.1.1 模板定义
```json
{
  "id": "ask-schedule",
  "name": "问日程",
  "icon": "📅",
  "category": "日常提效",
  "prompt": "{{text}}",
  "isBuiltin": true,
  "isScheduleQuery": true
}
```

#### 3.1.2 交互流程
1. 用户点击"📅 问日程"按钮
2. 输入框自动填入"今天有什么日程安排？"
3. 自动触发发送
4. 系统查询日历数据并注入上下文
5. AI 基于数据回答

### 3.2 自然语言检测

#### 3.2.1 触发关键词
| 关键词 | 示例 |
|--------|------|
| 日程 | "今天有什么日程？" |
| 会议 | "明天有会议吗？" |
| 安排 | "这周有什么安排？" |
| 行程 | "我的行程是什么？" |
| 今天有什么 | "今天有什么事？" |
| 明天有什么 | "明天有什么？" |
| 这周 | "这周忙吗？" |

#### 3.2.2 检测逻辑
```javascript
const scheduleKeywords = ['日程', '会议', '安排', '行程', '今天有什么', '明天有什么', '这周'];
const isScheduleQuery = scheduleKeywords.some(keyword => question.includes(keyword));
```

### 3.3 上下文注入

#### 3.3.1 注入格式
```
以下是用户的日历数据，请基于这些数据回答用户的问题。
如果用户问的是今天的日程，请列出今日日程；
如果问明天或这周，请根据数据回答。
如果数据中没有相关信息，请告知用户。

【今日日程】
1. 10:00-11:00 产品评审会 @ 3楼会议室
2. 14:00-15:00 技术方案讨论 @ 线上

【即将到来的事件（未来24小时）】
1. 8/9 10:00 产品评审会
2. 8/9 14:00 技术方案讨论

用户问题：今天有什么会议？
```

#### 3.3.2 数据来源
- 今日日程：`window.electronAPI.getTodayEvents()`
- 即将到来：`window.electronAPI.getUpcomingEvents()`

### 3.4 异常处理

| 场景 | 处理方式 |
|------|----------|
| 日历未配置 | AI 回答："您还未配置日历，请先在设置中添加日历源" |
| 日历无数据 | AI 回答："今天没有日程安排" |
| 日历查询失败 | 使用原始问题发送，不注入上下文 |
| 网络异常 | 使用原始问题发送 |

## 4. 非功能需求

### 4.1 性能需求
- 日程查询响应时间: < 100ms（本地查询）
- 上下文注入不增加明显延迟

### 4.2 用户体验
- 点击按钮后立即响应
- AI 回答基于真实数据，准确可靠
- 错误情况下不阻塞对话

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 日程数据过长 | 上下文超限 | 限制显示最近 5 个事件 |
| AI 理解错误 | 回答不准确 | 优化注入格式，明确指令 |
| 日历未配置 | 无法查询 | 检测配置状态，给出提示 |
