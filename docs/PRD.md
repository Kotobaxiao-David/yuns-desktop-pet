# 持久会议提醒 + CalDAV 设置指引 - PRD

## 1. 文档概览

### 1.1 功能名称
- 持久会议提醒气泡
- CalDAV 设置指引

### 1.2 目标用户
- 使用日历提醒功能的用户
- 首次配置 CalDAV 的用户

### 1.3 核心价值
- 持久提醒：确保用户不会错过重要会议，必须手动关闭才能消失
- 设置指引：降低 CalDAV 配置门槛，提供官方文档链接

---

## 2. 用户故事与范围

### 2.1 用户故事

**持久提醒气泡：**
1. 作为用户，我想要会议提醒持续显示在桌宠上方，直到我点击关闭
2. 作为用户，我想要看到会议的标题、时间、地点等详细信息
3. 作为用户，我想要通过 [x] 按钮关闭提醒

**CalDAV 设置指引：**
4. 作为用户，我想要在配置 CalDAV 时看到官方指引链接
5. 作为用户，我想要点击链接直接跳转到官方文档

### 2.2 范围

#### In-Scope

**持久提醒气泡：**
1. HTML 覆盖层显示在桌宠上方
2. 显示会议标题、时间、地点
3. 右上角 [x] 关闭按钮
4. 点击关闭，不自动消失
5. 淡入动画效果

**CalDAV 设置指引：**
1. 在 CalDAV 字段区域显示指引提示框
2. 飞书官方文档链接
3. 钉钉官方文档链接
4. 点击链接在默认浏览器中打开

#### Out-of-Scope
1. 多个会议同时显示列表
2. 气泡跟随桌宠移动
3. 气泡内按钮操作（如"稍后提醒"）

---

## 3. 功能需求

### 3.1 持久提醒气泡

#### 3.1.1 UI 设计

```
┌─────────────────────────────┐
│ ⏰ 会议提醒              [x] │  ← 标题栏（橙色渐变）
├─────────────────────────────┤
│ 产品评审会                   │  ← 会议标题（加粗）
│ 🕐 10:00                    │  ← 时间
│ 📍 3楼会议室                 │  ← 地点
│ 5分钟后开始                  │  ← 倒计时（橙色）
└─────────────────────────────┘
           ▼
      ┌─────────┐
      │  桌宠   │
      └─────────┘
```

#### 3.1.2 样式规格
- 位置：桌宠上方 140px，水平居中
- 尺寸：最小宽度 200px，最大宽度 280px
- 圆角：12px
- 阴影：0 4px 20px rgba(0, 0, 0, 0.15)
- 标题栏：橙色渐变 (#FF9800 → #FF5722)
- 动画：淡入 0.3s ease

#### 3.1.3 交互规则
- 显示后不自动消失
- 点击 [x] 按钮关闭
- 新提醒到来时替换当前显示的提醒

### 3.2 CalDAV 设置指引

#### 3.2.1 UI 设计

```
┌─────────────────────────────────────────────┐
│ 📖 如何获取 CalDAV 账号？                    │
│                                             │
│ 🔵 飞书官方指引 →                            │
│ 🟣 钉钉官方指引 →                            │
└─────────────────────────────────────────────┘
```

#### 3.2.2 链接地址
- 飞书：`https://www.feishu.cn/hc/zh-CN/articles/360043178673`
- 钉钉：`https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/jkB7yl4ZK3vV6qvBNMZgWPMX2O6oxqw0`

#### 3.2.3 样式规格
- 背景：浅黄色 (#FFF8E1)
- 边框：1px solid #FFE0B2
- 圆角：8px
- 链接颜色：#1976D2
- 暗色模式适配

## 4. 非功能需求

### 4.1 性能需求
- 气泡显示响应时间: < 100ms
- 链接打开响应时间: < 500ms

### 4.2 用户体验
- 气泡动画流畅
- 链接点击后在默认浏览器打开
- 暗色模式下样式正常
