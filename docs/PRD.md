# 持久会议提醒 + CalDAV 设置指引 - PRD

## 1. 文档概览

### 1.1 功能名称
- 持久会议提醒气泡
- CalDAV 设置指引

### 1.2 目标用户
- 使用日历提醒功能的用户
- 首次配置 CalDAV 的用户

### 1.3 核心价值
- 持久提醒：确保用户不会错过重要会议，从提醒时间到会议结束持续显示
- 设置指引：降低 CalDAV 配置门槛，提供官方文档链接

---

## 2. 用户故事与范围

### 2.1 用户故事

**持久提醒气泡：**
1. 作为用户，我想要会议提醒从提前X分钟开始持续显示，直到会议结束
2. 作为用户，我想要看到会议的标题、时间、地点等详细信息
3. 作为用户，我想要通过 [x] 按钮手动关闭提醒
4. 作为用户，我想要会议结束后提醒自动消失

**CalDAV 设置指引：**
5. 作为用户，我想要在配置 CalDAV 时看到官方指引链接
6. 作为用户，我想要点击链接直接跳转到官方文档

### 2.2 范围

#### In-Scope

**持久提醒气泡：**
1. HTML 覆盖层显示在桌宠上方
2. 显示会议标题、时间（开始-结束）、地点
3. 右上角 [x] 关闭按钮
4. 从提醒时间到会议结束持续显示
5. 用户可手动关闭
6. 会议结束后自动消失
7. 淡入动画效果

**CalDAV 设置指引：**
1. 在 CalDAV 字段区域显示指引提示框
2. 飞书官方文档链接
3. 钉钉官方文档链接
4. 点击链接在默认浏览器中打开

#### Out-of-Scope
1. 多个会议同时显示列表
2. 气泡跟随桌宠移动
3. 气泡内按钮操作（如"稍后提醒"）

## 3. 功能需求

### 3.1 持久提醒气泡

#### 3.1.1 UI 设计

```
┌─────────────────────────────┐
│ ⏰ 会议提醒              [x] │  ← 标题栏（橙色渐变）
├─────────────────────────────┤
│ 产品评审会                   │  ← 会议标题（加粗）
│ 🕐 10:00 - 11:00            │  ← 时间段
│ 📍 3楼会议室                 │  ← 地点
│ 会议进行中                   │  ← 状态（橙色）
└─────────────────────────────┘
           ▼
      ┌─────────┐
      │  桌宠   │
      └─────────┘
```

#### 3.1.2 样式规格
- 位置：桌宠上方 140px，水平居中
- 尺寸：最小宽度 200px，最大宽度 280px
- 圆角：12px
- 阴影：0 4px 20px rgba(0, 0, 0, 0.15)
- 标题栏：橙色渐变 (#FF9800 → #FF5722)
- 动画：淡入 0.3s ease

#### 3.1.3 交互规则
- **触发时间**：会议开始前X分钟（用户配置或日历自带）
- **持续显示**：从提醒时间到会议结束
- **手动关闭**：点击 [x] 按钮关闭，同一会议不再显示
- **自动消失**：会议结束后自动隐藏
- **新提醒**：如果有多个会议，显示最近的一个

#### 3.1.4 状态流转

```
提醒时间到达
    ↓
显示泡泡（activeReminders 添加）
    ↓
┌─────────────────────────────────────┐
│ 泡泡持续显示                         │
│ 用户可点击 [x] 关闭                  │
└─────────────────────────────────────┘
    ↓                        ↓
用户点击关闭              会议结束
    ↓                        ↓
dismissedReminders 添加    自动隐藏
    ↓                        ↓
同一会议不再显示          activeReminders 移除
```

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 气泡遮挡桌宠交互 | 中 | 设置合理的 z-index |
| 外部链接无法打开 | 低 | 使用 shell.openExternal |
| 暗色模式样式异常 | 低 | 添加暗色模式适配 |
| 多个会议同时提醒 | 中 | 显示最近的一个会议 |
