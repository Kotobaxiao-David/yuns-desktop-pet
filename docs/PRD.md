# Yuns 桌面宠物 - macOS 二次元桌宠改造 PRD

## 1. 文档概览

### 1.1 功能名称
macOS 二次元桌面宠物改造

### 1.2 目标用户
- macOS 用户
- 二次元文化爱好者
- 需要 AI 对话助手的用户
- 希望桌面更有趣味的用户

### 1.3 核心价值/目标
将现有的 Electron 桌面宠物改造为具有二次元风格、支持桌面闲逛和丰富互动的 macOS 桌宠应用，同时保留原有的 AI 对话功能。

---

## 2. 用户故事与范围

### 2.1 用户故事

**作为 macOS 用户，我想要：**
1. 一个可爱的二次元角色在桌面上闲逛，让桌面更有趣
2. 点击桌宠可以触发不同的互动反应
3. 双击桌宠可以打开 AI 对话窗口
4. 桌宠可以显示当前心情状态
5. 桌宠可以提醒我休息或喝水
6. 桌宠可以显示系统状态（时间、电量等）

### 2.2 范围

#### In-Scope（本次开发范围）
1. **二次元角色系统**
   - 更换为二次元风格角色（像素风/矢量风）
   - 支持多种待机动画
   - 支持多种表情状态

2. **桌面闲逛功能**
   - 桌宠在屏幕底部随机移动
   - 支持行走、站立、坐下等状态
   - 避开屏幕边缘和 Dock 栏

3. **点击互动系统**
   - 单击：摸头反应（爱心特效）
   - 双击：打开 AI 对话窗口
   - 右键：显示功能菜单
   - 拖拽：移动桌宠位置

4. **桌面对话气泡**
   - 定时显示有趣的对话气泡
   - 支持自定义对话内容
   - 显示系统状态信息

5. **心情系统**
   - 根据互动频率变化心情
   - 不同心情显示不同表情
   - 心情影响对话内容

6. **保留原有功能**
   - AI 多模型对话
   - MCP 工具调用
   - 视觉分析
   - 设置界面

#### Out-of-Scope（暂不开发）
1. 多角色切换
2. 语音交互
3. 桌宠之间的互动
4. 移动端支持
5. 社交分享功能

## 3. 功能需求

### 3.1 二次元角色系统

#### 3.1.1 角色设计
- **风格**：像素风二次元角色（16x16 或 32x32 像素）
- **角色**：可爱的猫耳少女/少年形象
- **配色**：粉色/蓝色系，符合二次元审美

#### 3.1.2 动画状态
| 状态 | 描述 | 帧数 |
|------|------|------|
| idle | 站立待机 | 4帧 |
| walk | 行走 | 6帧 |
| sit | 坐下 | 4帧 |
| sleep | 睡觉 | 4帧 |
| happy | 开心 | 4帧 |
| sad | 难过 | 4帧 |
| angry | 生气 | 4帧 |
| surprised | 惊讶 | 2帧 |

#### 3.1.3 动画切换规则
- 空闲 30秒：切换到 sit 状态
- 空闲 60秒：切换到 sleep 状态
- 点击互动：切换到 happy/surprised 状态
- 长时间无互动：切换到 sad 状态

### 3.2 桌面闲逛功能

#### 3.2.1 移动规则
- **移动范围**：屏幕底部区域（距底部 0-100px）
- **移动速度**：1-3 像素/帧
- **移动方向**：随机左右移动
- **边界检测**：碰到屏幕边缘改变方向

#### 3.2.2 状态切换
- 行走 5-10秒：随机切换到站立
- 站立 3-8秒：随机切换到行走
- 点击互动：停止移动，显示互动动画
- 双击：停止移动，打开对话窗口

#### 3.2.3 避障规则
- 避开 Dock 栏区域
- 避开其他窗口（可选）
- 避开屏幕边缘 50px 范围

### 3.3 点击互动系统

#### 3.3.1 互动类型
| 互动 | 触发方式 | 反应 |
|------|----------|------|
| 摸头 | 单击 | 显示爱心特效，心情+10 |
| 拍肩 | 单击肩膀区域 | 显示惊讶表情 |
| 喂食 | 拖拽食物图片 | 显示开心表情，心情+20 |
| 移动 | 拖拽桌宠 | 移动到新位置 |
| 对话 | 双击 | 打开 AI 对话窗口 |
| 菜单 | 右键 | 显示功能菜单 |

#### 3.3.2 特效系统
- **爱心特效**：点击时从点击位置飘出 3-5 个爱心
- **星星特效**：开心时从头顶飘出星星
- **汗滴特效**：尴尬时显示汗滴

### 3.4 桌面对话气泡

#### 3.4.1 触发条件
- 定时触发：每 5-10 分钟随机显示
- 事件触发：收到通知、电量低、定时提醒
- 互动触发：点击后显示感谢话语

#### 3.4.2 对话内容分类
| 分类 | 示例 |
|------|------|
| 日常问候 | "早上好呀~"、"今天也要加油哦！" |
| 系统提醒 | "该休息眼睛啦~"、"电量只剩 20% 了" |
| 心情表达 | "好开心见到你~"、"有点无聊呢..." |
| 趣味对话 | "你知道吗？猫咪每天要睡 16 小时哦~" |

#### 3.4.3 显示规则
- 气泡显示 3-5 秒后自动消失
- 点击气泡可以关闭
- 同时只显示一个气泡

### 3.5 心情系统

#### 3.5.1 心情值范围
- **范围**：0-100
- **初始值**：50
- **衰减**：每小时 -5

#### 3.5.2 心情等级
| 等级 | 心情值 | 表情 | 对话风格 |
|------|--------|------|----------|
| 非常开心 | 80-100 | 😊 | 热情、活泼 |
| 开心 | 60-79 | 😊 | 友好、积极 |
| 普通 | 40-59 | 😐 | 平淡、正常 |
| 难过 | 20-39 | 😢 | 低落、需要安慰 |
| 非常难过 | 0-19 | 😭 | 沉默、偶尔叹息 |

#### 3.5.3 心情影响因素
- **正面互动**：+5 到 +20
- **长时间无互动**：-5/小时
- **收到礼物**：+10 到 +30
- **被忽略**：-10/天

## 4. 非功能需求

### 4.1 性能需求
- **CPU 占用**：< 5%（idle 状态）
- **内存占用**：< 200MB
- **动画帧率**：30fps（流畅）
- **响应时间**：< 100ms（点击响应）

### 4.2 兼容性需求
- **系统版本**：macOS 11.0+
- **屏幕分辨率**：支持 Retina 显示
- **多显示器**：支持在主显示器显示

### 4.3 用户体验需求
- **启动时间**：< 3秒
- **动画流畅**：无卡顿
- **交互反馈**：即时响应
- **资源占用**：不影响其他应用

### 4.4 可维护性需求
- **代码结构**：模块化设计
- **配置灵活**：支持自定义设置
- **扩展性**：易于添加新角色/动画

## 5. 技术约束与依赖

### 5.1 技术栈
- **框架**：Electron 28.0.0
- **前端**：HTML5 Canvas / CSS Animation
- **后端**：Node.js
- **存储**：electron-store
