# 桌面宠物角色切换功能 - PRD

## 1. 文档概览

### 1.1 功能名称
桌面宠物角色切换系统

### 1.2 目标用户
- 想要自定义桌宠外观的用户
- 像素艺术爱好者
- 希望拥有多个桌宠角色的用户

### 1.3 核心价值
让用户可以自由更换桌面宠物的外观，支持内置预设角色和自定义角色，提升个性化体验。

---

## 2. 用户故事与范围

### 2.1 用户故事

**作为用户，我想要：**
1. 从多个内置角色中选择我喜欢的桌宠外观
2. 导入自己制作的像素角色 sprite sheet
3. 在设置界面中预览并切换角色
4. 角色切换后保留心情、对话等状态数据
5. 每个角色有不同的调色板（颜色风格）

### 2.2 范围

#### In-Scope
1. **内置角色预设系统**
   - 定义角色数据结构（调色板 + 像素模板）
   - 预置 3-5 个角色（猫耳少女、狗耳少年、兔耳娘、小恶魔、史莱姆）
   - 角色信息存储在配置文件中

2. **外部 Sprite Sheet 加载**
   - 支持导入 PNG 格式的 sprite sheet
   - 定义标准 sprite sheet 格式规范
   - 从 sprite sheet 提取各状态动画帧

3. **角色选择 UI**
   - 设置界面中添加"角色选择"标签页
   - 显示角色缩略图预览
   - 显示角色名称和描述
   - 支持点击切换角色

4. **角色数据持久化**
   - 保存用户选择的角色 ID
   - 保存自定义 sprite sheet 路径
   - 应用启动时自动加载上次选择的角色

#### Out-of-Scope
1. 角色编辑器（在线绘制像素画）
2. 角色动画编辑
3. 角色商店/在线下载
4. 多角色同时显示

---

## 3. 功能需求

### 3.1 角色数据结构

#### 3.1.1 角色预设定义
```
CharacterPreset {
  id: string           // 唯一标识，如 "catGirl"
  name: string         // 显示名称，如 "猫耳少女"
  description: string  // 角色描述
  author: string       // 作者（可选）
  version: string      // 版本号
  palette: {           // 调色板
    hair: string       // 头发主色 (hex)
    hairDark: string   // 头发暗部
    skin: string       // 肤色
    eye: string        // 眼睛颜色
    eyeWhite: string   // 眼白
    eyePupil: string   // 瞳孔
    mouth: string      // 嘴巴
    blush: string      // 腮红
    cloth: string      // 衣服
    accent: string     // 点缀色
  }
  ears: string         // 耳朵类型: "cat" | "dog" | "bunny" | "devil" | "none"
}
```

#### 3.1.2 Sprite Sheet 格式规范
```
文件格式: PNG (支持透明通道)
尺寸: 192x256 像素 (6列 x 8行，每帧 32x32)
命名: {characterId}_sprites.png

布局:
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  0  │  1  │  2  │  3  │  -  │  -  │  Row 0: idle (4帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  2  │  3  │  4  │  5  │  Row 1: walk (6帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  2  │  3  │  -  │  -  │  Row 2: sit (4帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  2  │  3  │  -  │  -  │  Row 3: sleep (4帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  2  │  3  │  -  │  -  │  Row 4: happy (4帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  -  │  -  │  -  │  -  │  Row 5: sad (2帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  -  │  -  │  -  │  -  │  Row 6: angry (2帧)
├─────┼─────┼─────┼─────┼─────┼─────┤
│  0  │  1  │  -  │  -  │  -  │  -  │  Row 7: surprised (2帧)
└─────┴─────┴─────┴─────┴─────┴─────┘

像素颜色约定:
- 透明区域: alpha < 128
- 建议使用调色板中的颜色，便于系统识别
```

#### 3.3.2 自定义角色导入
- 点击"导入自定义角色"按钮
- 选择 PNG 文件
- 验证 sprite sheet 格式
- 填写角色名称和描述
- 保存到用户数据目录

## 4. 非功能需求

### 4.1 性能需求
- 角色切换响应时间: < 500ms
- Sprite sheet 加载时间: < 1s
- 内存占用增量: < 50MB（加载自定义角色后）

### 4.2 兼容性需求
- 支持 PNG 格式（8位/24位/32位）
- 支持 Retina 显示（自动缩放）
- Sprite sheet 最大尺寸: 512x512

### 4.3 用户体验需求
- 角色切换后立即生效
- 预览图清晰可见
- 导入失败时显示友好错误提示

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |

| Sprite sheet 格式不统一 | 高 | 提供模板下载 + 严格验证 |
